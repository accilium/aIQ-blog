# aIQ-blog

Source for [**aIQ**](https://accilium.github.io/aIQ-blog/), accilium's blog on
artificial intelligence, re-architecting work, and the craft of building
reliable AI systems.

## What this is

A Jekyll site served via GitHub Pages. Markdown in, static site out. No CMS,
no tracking, no comment system. Posts live in [`_posts/`](_posts/) as plain
Markdown files with frontmatter.

We post roughly once every two weeks. Quality over cadence — no AI-generated
filler, no LinkedIn-thought-leader prose. Each post is authored and signed.

## Why this repo is public

We are open-sourcing how we build the consultancy. The substance lives in
the rendered site; the source, the commit history, and the rough edges of how
it gets built are all part of what we're sharing. If you want to see how the
sausage is made, the repo is the sausage factory.

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000/aIQ-blog/>.
